# Live 30-day experiment run

A committed copy of one `make experiment` run over **real, live-ingested news**,
as a companion to [`../baseline`](../baseline), which runs over the synthetic
fixtures. Both are needed: the fixtures are reproducible offline and carry
curated story labels; this run is real but can only be labelled by the system
itself.

Source directory: `artifacts/experiments/2026-08-24T071314Z` (regenerated
directories under `artifacts/` are gitignored). The projector `.joblib` files
and the Parquet tables are not copied here — they are large and regenerated by
`make experiment`.

## Corpus

3,191 articles ingested from GDELT DOC 2.0 and 36 public publisher feeds
(`configs/topics.live.yaml`) across 292 domains. The sweep evaluates the **last
30 days** (1,120 articles) via `--since-days 30`: several feeds are vendor blog
archives reaching back to 2015, and without the window a decade-old post would
sit in the fit period while this morning's wire story sat in the test period.

Reproduce the shape of it — not the contents, since the feeds move:

```bash
NEWSTRACE_DATABASE_URL=sqlite:///./newstrace_live.db \
NEWSTRACE_TOPICS_FILE=configs/topics.live.yaml \
  uv run alembic upgrade head

NEWSTRACE_DATABASE_URL=sqlite:///./newstrace_live.db \
NEWSTRACE_TOPICS_FILE=configs/topics.live.yaml \
  uv run newstrace ingest --source rss

NEWSTRACE_DATABASE_URL=sqlite:///./newstrace_live.db \
NEWSTRACE_TOPICS_FILE=configs/topics.live.yaml \
  uv run python scripts/run_experiments.py --since-days 30 --max-queries 200 --seed 549
```

## What this run shows

- **Compression is free here.** SVD at d=32 holds a 12× smaller index and scores
  *above* the full-dimensional baseline (nDCG@10 0.875 vs 0.833), with p95 query
  latency 7× lower (0.09 ms vs 0.64 ms). At 1,120 vectors latency is finally
  large enough to measure, unlike the 135-vector fixture run.
- **Nothing is statistically separable.** Every paired bootstrap interval
  against the full baseline contains zero across all twelve configurations. The
  honest reading is *not* "d=32 is better" — it is "23 silver queries cannot
  tell these representations apart".
- **PageRank helps here and hurt on the fixtures.** Reranking scores nDCG@10
  0.874 against the 0.833 cosine baseline, the reverse of the fixture run
  (0.881 vs 0.914). One corpus is a graph of 8,367 nodes over real syndication
  patterns; the other is 575 nodes of generated text. Neither settles the
  question.
- **Duplicates are excluded from the relevant set.** A syndicated copy is not
  independent coverage, so retrieving one earns no credit. With copies left in,
  every method scored an identical 0.917 — the task was simply "find the
  near-identical article", which no representation can fail.

## What this run cannot show

Relevance judgments came from the system's own full-dimensional clustering.
Silver labels of that kind measure self-consistency, not human-judged relevance,
and they flatter the baseline that produced them. Only 23 queries survived, and
the live corpus holds 59 multi-article stories in the window, of which 32 have
two or more non-duplicate articles — real multi-source events are rare in a
one-month feed sample. The feed list is also a convenience sample dominated by
English-language technology outlets and vendor blogs. See
[../../limitations.md](../../limitations.md).
