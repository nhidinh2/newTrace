# Baseline experiment run (synthetic fixtures)

A committed copy of one `make experiment` run over the synthetic fixtures, so
every number quoted in [../../evaluation.md](../../evaluation.md) and
[../../model_card.md](../../model_card.md) can be checked against the
measurements that produced it.

Source directory: `artifacts/experiments/2026-08-24T071319Z` (regenerated
directories under `artifacts/` are gitignored).

The projector `.joblib` files and the per-query/per-configuration Parquet
tables are **not** copied here — they are large and are regenerated by
`make experiment`. Everything needed to audit the reported figures is:

| File | Contents |
| --- | --- |
| `metrics.json` | Every measurement, machine readable |
| `config.json` | Methods, dimensions, seed, query budget |
| `environment.json` | Python, package versions, platform, seed, git commit |
| `report.md` | Rendered report, generated *from* `metrics.json` |
| `quality_vs_*.png` | Quality against dimension, memory and p95 latency |

Reproduce with:

```bash
make clean && make db && make demo && make experiment
```

The run is seeded (549) and deterministic: quality and distortion figures
reproduce exactly on the same corpus. Latency figures will not, and on a corpus
of 135 vectors they are noise — see the evaluation doc.

For the same sweep over real, live-ingested articles, see
[`../live-30d`](../live-30d).
